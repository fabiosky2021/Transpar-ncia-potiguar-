Este aplicativo foi desenvolvido para atuar como uma plataforma oficial de utilidade pública e transparência cívica durante o segundo turno das eleições. O projeto foi programado com o compromisso de garantir o acesso à informação de forma ética e transparente, servindo exclusivamente a boas intenções e ao fortalecimento do processo democrático no Rio Grande do Norte. Utilize-a com responsabilidade, respeitando as diretrizes democráticas e a LGPD.
